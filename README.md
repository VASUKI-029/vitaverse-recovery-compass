==================================================

Create a premium, elegant splash screen for VITAVERSE AI.

IMPORTANT:

There is NO uploaded logo to use.

DO NOT ask for a logo.

DO NOT reference an uploaded image.

DO NOT generate a separate logo asset.

Instead, create a beautiful text-based premium splash screen using typography and subtle visual elements.

Background:

Use the VITAVERSE warm ivory / champagne aesthetic:

#F5F1E9

The center of the screen should contain:

VITAVERSE AI

Use elegant, premium typography.

Below it, display:

AI-Powered Adaptive Recovery

Do NOT fill the splash screen with descriptions.

Optional subtle visual element:

Create a very minimal abstract futuristic healthcare/AI element behind or around the text using soft gradients, thin curved lines, subtle particles, or a very faint digital-twin inspired pattern.

The visual must remain extremely subtle.

Do NOT create a large complicated logo.

Do NOT use a generic medical cross.

Do NOT use a hospital icon.

Do NOT make it look like a generic healthcare application.

The splash screen should feel:

Premium

Minimal

Futuristic

Calm

Elegant

Professional

2. "VITAVERSE AI" fades in.

3. Subtitle fades in slightly after the title.

4. Add a very subtle scale/opacity animation.

5. Hold briefly.

6. Everything gently fades out.

0–700ms:

Background + title fade in.

700–1400ms:

Subtitle fades in.

1400–2200ms:

Subtle premium animation.

2200–3000ms:

Gentle fade out.

Then automatically navigate to:

Language Selection.

The splash screen must be responsive on:

Mobile

Tablet

Desktop
